## 第 1 步：先看看你的机器上已经有什么

**我在做什么：** 检查 macOS 版本、Python 3.11 或更高版本、Xcode 命令行工具，以及是否装了
智能体命令行。这一步不安装任何东西，只是查看。

**为什么：** 扫描件识别依赖 Apple Vision，它只存在于 Mac 上。现在知道，好过装到一半才知道。

**磁盘上会改变什么：** 什么都不改。这一步只读。

**你会得到：** 一份缺失清单，每一项都配一条命令。

**岔路：** 手边没有 Mac。忒弥兹在别的系统上也能跑，但读不了扫描件：识别会失效，其余功能保留。
告诉我是就这样继续，还是你带着 Mac 回来。

## 第 2 步：安装依赖

**我在做什么：** 运行 `bash install.sh`。安装分七步走：Python 包、用于法院文书的 PT Serif
字体、Apple Vision 识别、用于转写录音的 ffmpeg、脚本执行权限、工作目录，以及智能体命令行。

**为什么：** 这是忒弥兹的身体。没有这些包就装配不出文书，没有字体它不像一份文书，
没有 ffmpeg 庭审录音就读不出来。

**磁盘上会改变什么：** Python 包进入项目环境，字体进入系统字体目录，工作目录
`cases/_logs`、`cases/_assets`、`knowledge`，以及桌面上的收件夹。每一步之前安装程序都会征求同意。

**你会得到：** 一套可用的安装，以及七个步骤各自的报告。

## 第 3 步：选择你的工作方式

**我在做什么：** 给你看通往同一座房子的四扇门：`claude`、`codex`、用编辑器打开的 `code .`，
以及完全不调用智能体的浏览器面板 `python3 cockpit/app.py`。

**为什么：** 智能体和规则住在项目里，而不是住在某一个工具里。你换工具，房子不变。

**磁盘上会改变什么：** 什么都不改。选一扇门不会重写任何东西。

**你会得到：** 你熟悉的环境，且忒弥兹的规则已经加载好。

**岔路：** 你根本不想让智能体接触案件材料。那就用浏览器面板：它显示案件状态，一次模型都不调用。

## 第 4 步：建立第一个案件

**我在做什么：** 询问委托人和案由，对照既往案件登记表检查利益冲突，创建目录结构，
把材料从收件夹搬进来。

**为什么：** 利益冲突要在开工之前查，而不是之后。如果我们曾经代理过对方，我会停下来告诉你。

**磁盘上会改变什么：** 新建目录 `cases/{委托人}/{案由}`，其中包含材料、草稿和成稿三类目录。
你的原始文件是复制过去的，原件留在原处。

**你会得到：** 一个建好的案件，以及一个关于利益冲突的诚实答复。

## 第 5 步：跑完办案流程

**我在做什么：** 用五个步骤推进案件。材料地图、对你有利和不利的判例检索、确定立场、
起草文书、由第二个智能体复核每一份文书。

**为什么：** 写文书的人不负责验收。复核者读磁盘，而不是读起草者的报告，
判定由仪器写入，而不是由复核者自己写。

**磁盘上会改变什么：** 案件地图、判例文件、立场文件、草稿和判定日志，全部位于案件目录内。
任何内容都不会离开该案件。

**你会得到：** 一整套文书，每一份都带判定和复核痕迹。最后一句话仍然属于你：
签发还是重写，由你决定。

## 第 6 步：确认一切都还活着

**我在做什么：** 运行各仪器的自检，并用一条命令显示案件状态。

**为什么：** 承诺要么成立，要么不成立。验证比相信便宜。

**磁盘上会改变什么：** 除了运行日志，什么都不改。

**你会得到：** 一份带退出码的仪器清单，以及案件摘要：哪一步已完成、下一步是什么、
哪里还缺材料。

```bash
./bin/vision-doc --selftest
python3 scripts/themiz_status.py cases/{委托人}/{案由} --brief
```
