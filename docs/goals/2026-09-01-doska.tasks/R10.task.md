## Промт исполнителя
ПОЙМАНО ЖИВЬЕМ 02.09.2026, 01:43. Прогон задачи, у которой в paths стоял ОДИН файл
scripts/loop_gate.py, перезаписал ЧЕТЫРЕ общемашинных хука git в ~/.agents/git-hooks. После этого
коммит в ЛЮБОМ репозитории без scripts/pd_guard.py падал:

    git init -q . && git add a.txt && git commit -m proba
    -> код 128, «fatal: ref updates aborted by hook»

Проверено до и после починки: 128 против 0. У владельца около сорока репозиториев, и почти во всех
этого прибора нет.

ИСТОЧНИК - функция установки в scripts/pd_guard.py, около строки 645:

    hooks = git("rev-parse", "--git-path", "hooks")
    for name, arg in (("pre-commit","--staged"), ("commit-msg",'--msg "$1"'),
                      ("pre-push","--push"), ("reference-transaction",'--ref-txn "$1"')):
        f.write(HOOK % arg); os.chmod(path, 0o755)

Три дефекта разом:
1) При заданном ГЛОБАЛЬНО core.hooksPath (у владельца он равен ~/.agents/git-hooks) rev-parse
   отдает ОБЩЕМАШИННЫЙ каталог. Прибор думает, что ставит хук себе, а ставит его всем.
2) Шаблон HOOK не содержит проверки существования прибора. Отсюда падение в чужих репозиториях.
   Правильный вид, он же восстановленный мной руками:
       pd_guard_script="$(git rev-parse --show-toplevel 2>/dev/null)/scripts/pd_guard.py"
       [ -f "$pd_guard_script" ] || exit 0
       exec python3 "$pd_guard_script" --staged
3) Прежний хук ЗАТИРАЕТСЯ без резерва и без цепочки. В commit-msg и pre-push у владельца живет
   цепочка Entire, а отслеживание сессий отключать НЕЛЬЗЯ - это его прямое правило. В этот раз
   цепочка уцелела по случайности, а не по устройству.

СДЕЛАЙ:
1) Шаблон хука обязан нести проверку существования прибора и тихо выходить нулем, если прибора нет.
2) Установка в ОБЩЕМАШИННЫЙ каталог (core.hooksPath задан вне репозитория) требует явного согласия
   флагом и громкого предупреждения с именем каталога. Молча писать в $HOME запрещено.
3) Существующий хук СОХРАНЯЕТСЯ рядом и ВЫЗЫВАЕТСЯ цепочкой, как это делает установщик Entire
   (посмотри на ~/.agents/git-hooks/commit-msg - там образец цепочки). Затирать чужой хук нельзя.
4) Селфтест обязан краснеть на каждом из трех пунктов. Фикстуру строй во временном репозитории
   со СВОИМ core.hooksPath, иначе проба испортит машину так же, как это сделал прогон.

ЗАПРЕТ: не ослаблять саму проверку персональных данных. Она сегодня зеленая 50 из 50 и ловит
фамилию постороннего доверителя даже голой - это трогать нельзя.
