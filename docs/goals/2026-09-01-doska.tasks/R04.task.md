## Промт исполнителя
Замерено сегодня. setup_doctor печатает:

    ✓ пакет fitz: импортируется
    ✓ самопроверки скриптов: 10/10 зеленые
    Итого: критично 0, предупреждений 0, проверок 17.
    Готово: все критичное на месте.

Все три строки вводят в заблуждение.

1) СЕЛФТЕСТОВ НЕ 10, А 61. Я прогнал все: зеленых 60, красный один - scripts/loop_gate.py.
   Доктор его не видит, потому что проверяет короткий список имен. Дом объявлен исправным при
   мертвом стороже цикла.
2) КАРТА МОДУЛЬ-ДИСТРИБУТИВ ВРЕТ И ОПАСНА. Строка 132 предлагает чинить отсутствующий модуль
   командой «pip install {mod}». Для модуля fitz это команда «pip install fitz» - на PyPI это
   ЧУЖОЙ пакет-сквоттер, не PyMuPDF. Для модуля docx - «pip install docx», тоже чужой заброшенный
   пакет вместо python-docx. Доктор советует установить постороннее.
3) Пакет fitz объявлен критичным (строка 389). Это PyMuPDF под AGPL-3.0. Пометку не снимай -
   вынос зависимости идет отдельной задачей, здесь только честность доктора.

СДЕЛАЙ:
1) Собери список селфтестов С ДИСКА, а не из константы: все файлы scripts/, содержащие --selftest.
   Красный любой из них - критично, с называнием имени и кода. Если полный прогон долог, дай флаг
   быстрого режима, но ПО УМОЛЧАНИЮ гоняй все: доктор зовется редко, а врет дорого.
2) Заведи карту модуль -> дистрибутив: fitz -> pymupdf, docx -> python-docx, и остальные, где имя
   импорта не совпадает с именем пакета. Проверь ВСЕ вызовы check_module в файле, не только два.
3) Добавь в --selftest проверку, которая краснеет, если карта неполна: для каждого check_module
   в файле обязана быть запись в карте либо совпадение имен.

НЕ ТРОГАЙ проверки сети, шрифтов, корпуса права и Apple Vision: они верные.
