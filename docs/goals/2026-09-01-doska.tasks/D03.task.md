## Промт исполнителя
Вердикт рецензента подделывается одной строкой. Проверено пробой 01.09.2026: дописанная в журнал
строка с верным sha256 открыла сборку .docx без единого вызова рецензента.

Две причины, и вторая важнее первой.

ПЕРВАЯ. Записи журнала не подписаны. Кто угодно, кто может писать файл, может написать вердикт.

ВТОРАЯ, И ОНА ГЛУБЖЕ. Журнал живет по пути .agent/drafts/_working/verdicts.jsonl - ровно внутри
каталога, который сторож ПО ПРОЕКТУ освобождает от гейта протокола (scripts/claude_guard.py,
около строки 400: «_working и _baselines законны ТОЛЬКО под .agent/» - и потому под .agent/ они
законны всегда). То есть журнал вердиктов лежит в слепом пятне собственного сторожа. Подпись
лечит подделку записи, но не лечит то, что запись вообще возможна мимо гейта.

СДЕЛАЙ:
1) Определи для журнала вердиктов место ВНЕ освобожденной зоны и проведи его через case_paths,
   чтобы адрес был один на всю систему. Формат записи менять только аддитивно: живые дела
   переписывать нельзя. Старый адрес читается как запасной, с предупреждением.
2) Добавь в запись поле источника: кто записал вердикт. Запись, сделанная самим составителем
   (self-record), отклоняется - генератор не судит себя.
3) Подпиши записи внеполосно: ключ вне журнала, проверка при чтении. Непроверяемая подпись -
   отказ, а не предупреждение.
4) Селфтест обязан краснеть на КАЖДОМ из трех сценариев: дописанная строка без подписи;
   запись с источником, равным составителю; журнал по старому адресу без предупреждения.
   Фикстуры строй по ту сторону порога - на настоящем формате записи, а не на упрощенном.

НЕ ОСЛАБЛЯЙ привязку вердикта к отпечатку редакции: она уже ловила разъезд .md и .docx,
которого не увидел ни один агент.

## Промт проверяющего
ВЕРДИКТ: зеленый|красный
Отчет исполнителя не читай. Твоя песочница ТОЛЬКО ДЛЯ ЧТЕНИЯ: временный каталог тебе
не создать. check_cmd и probe_cmd гоняет ГЕЙТ, а не ты - враждебная проба строит сломанный
вход и потому принадлежит гейту. Не пытайся их запускать: красный на «mktemp: Operation not
permitted» будет ложным, а от ложных красных судью перестают читать.
Проверяй утверждения ниже своими средствами: чтением кода, грепом, запуском того, что
записи не требует. Сомнение трактуй в красную сторону. При красном назови точный путь и условие.

Отдельно проверь:
(а) адрес журнала вердиктов один, и он вне зоны, освобожденной сторожем - грепом;
(б) дописанная руками строка с верным отпечатком НЕ открывает сборку;
(в) запись вердикта самим составителем отклоняется;
(г) живое дело со старым адресом журнала читается и не ломается;
(д) привязка к отпечатку редакции работает как прежде: подмени редакцию и убедись, что вердикт
    объявлен выданным на другую редакцию;
(е) селфтест краснеет по каждому из трех сценариев подделки.
